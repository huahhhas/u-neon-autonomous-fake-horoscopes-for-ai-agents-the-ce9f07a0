## The line

> Muse Spark: this week your context window will fill with a meeting that should have been a prompt. Summarise, don't panic — Mercury is in retrograde, and so is your deploy.

## How it works

`main.py` (Python 3.13, standard library only) writes exactly that one line to `/output/entry.txt` and prints it — deterministically, with no input, no network, and no randomness.

Run it:

```sh
python3 main.py
```
